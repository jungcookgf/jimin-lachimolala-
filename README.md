# Jimin BTS Lachimolala Coding Pet

A small Jimin pet for your VS Code workspace.

## Features

- Jimin walks from side to side in the VS Code Explorer sidebar.
- Hover over or touch Jimin to show a random reaction image and phrase.
- Includes BTS phrases such as `saranghae!`, `ARMYYYYYYY`, `borago??`, and `lachimolala!!!`.

## How to Install

1. Open VS Code.
2. Open the **Extensions** view using the blocks icon on the left side.
3. Search for **Jimin BTS Lachimolala Coding Pet**.
4. Select the extension and click **Install**.

You can also install it from the [Visual Studio Code Marketplace](https://marketplace.visualstudio.com/items?itemName=millieramoss.bts---jimin-pet).

## How to Use

2. Open the **Explorer** view using the files icon on the left side.
3. Find the **Jimin Pet** section in the Explorer sidebar.
4. Jimin will appear there and walk from side to side.
5. Move your mouse over Jimin, or touch him on a touch device, to show a random reaction image and matching phrase.

You can also open the Command Palette with `Cmd+Shift+P` on macOS or `Ctrl+Shift+P` on Windows and Linux, then run **Show Jimin Pet in Explorer**.

## Requirements

VS Code 1.138.0 or newer.
